# 🚀 UNQ UI - Leonardo Troche - Trabajo Final

## 📥 Descargar el proyecto

Clonar el repositorio:

```bash
git clone https://github.com/leotroche/unq-ui-leonardo-troche-trabajo-final.git
```

Ingresar a la carpeta del proyecto:

```bash
cd unq-ui-leonardo-troche-trabajo-final
```

Instalar las dependencias:

```bash
pnpm install
```

## ▶️ Ejecutar localmente

Iniciar la aplicación:

```bash
pnpm run dev
```
